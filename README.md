一、实践周完成内容说明：
1.毕设推进：在五一假期期间我实现了在毕设系统的前端筛选谷歌地图上某城市缺乏中文翻译或中文翻译不准确的地理名称并显示在系统前端的工作，是毕业设计的一项重要的功能。
2.专业学习：在五一假期期间我阅读了《计算机文化》原书第20版，并获得了启发，以下是读书笔记内容：
    这本书开篇解释了什么是计算机文化，书里的说法是“计算机文化的真正内涵是培养人具有计算机信息处理能力”。这句话改变了我对计算机的认识。以前我觉得会编程、会用各种软件就算是懂计算机了，但现在我明白，真正的计算机文化是一种思维能力——在信息很多的时候怎么筛选有用的信息、怎么判断信息的真假、怎么运用信息解决实际问题。书中还把计算机文化称为人类文化发展的第四个里程碑，前三个是语言、文字和印刷术。这个说法让我重新看待自己身处的这个时代，我们正经历着一场巨大的变革，只是平时没怎么意识到罢了。书中关于社交媒体的内容让我印象很深。书上写道：“社交媒体从根本上改变了人类互动的方式，它创造了前所未有的连接可能，同时也带来了身份、声誉和隐私的新挑战。”我每天都要用微信、刷抖音，但从来没有认真想过这些平台是怎么影响我的生活的。看完书我才意识到，我们在社交平台上展示的不是完整的自己，而是经过挑选和修饰的样子。点赞数不知不觉成了衡量自己受欢迎程度的标准，花在刷视频上的时间也越来越长。更让我警醒的是，书中说这些平台的商业模式就是靠出售用户的注意力来赚钱。这让我开始重新思考自己和手机之间的关系。关于网络安全的部分也让我学到了很多。书中说：“互联网的匿名性为不法分子提供了天然庇护，而技术漏洞中最薄弱的环节永远是——人。”我以前觉得只要装了杀毒软件、密码设得复杂一些就安全了，但书里讲到很多网络攻击利用的不是技术漏洞，而是人的心理弱点。那些假装是银行客服打来的电话、那些要求输入验证码的短信链接，其实都是在骗人。这让我明白，保护自己在网上的安全，光靠软件是不够的，自己也要多留个心眼。最后关于编程的那一章也很有意思。书里强调学编程不一定是为了当程序员，而是为了培养一种思考方式——把一个复杂的问题拆解成一步步可以操作的小步骤，然后按顺序解决。这种能力不管学什么专业、做什么工作都用得上。书中说编程正在成为阅读、写作、算术之后的第四项基本能力，我觉得这个说法挺有道理的。
    读完这本书，我最大的收获不是背下了多少技术名词，而是学会了一种看待技术的新角度。技术不是中立的工具，它在悄悄改变我们怎么想问题、怎么和人相处、怎么看待这个世界。《计算机文化》让我明白，在使用技术的时候要多想一想，既要享受技术带来的方便，也要保持自己的判断力。这可能就是计算机文化的真正意义——不做技术的奴隶，做一个有想法的数字时代的普通人。

二、毕设推进详细过程：
  在假期期间，我着力于如何实现在谷歌地图上筛选出孟加拉国锡尔赫特市范围内所有不含中文翻译或中文翻译不准确的地理名称，将其显示在系统前端供用户使用。在一开始我边上网站查阅资料，搜寻可以用来爬取谷歌地图上某一城市地理名称的工具，找到一下几个方法，一是用谷歌地图api自带的Places库以搜索查询的方式获得地理位置名称，但Places库只能获取商业名称（如商店、餐厅等），无法获取地理名称（如行政区划、街道、河流等），另一方法是完全自己编辑爬虫代码，爬取网页来获取名称，但实现难度较高，且易被谷歌系统识别从而拒绝服务，另外还有一些其它库也是各有优缺点，通过反复测试，最终我实现了将锡尔赫特市大部分地理名称（包括商业名称）爬取下来且保存到文件中，显示在系统前端。
  
三、问题及解决方法：在推进毕设系统功能时，如何将谷歌的Places库与手动编辑爬虫代码结合起来以更好的实现爬取操作是个问题，同时也伴随着爬取的名称不符合要求，希望爬取到孟加拉语名称最后却没有爬到、希望保存中文名称却保存了英文名称等现象频繁出现，于是我通过访问CSDN以及其他网站查阅相关资料、同时借助大模型修改润色代码，最后解决了问题。

四：实践总结：本周正值五一假期，我主要完成了两项任务：毕业设计功能推进和《计算机文化》阅读。毕设方面，我实现了在系统前端筛选并显示孟加拉国锡尔赫特市范围内缺乏中文翻译或翻译不准确的地理名称。起初尝试用谷歌地图API自带的Places库，发现只能获取商业名称，无法获取街道、河流等地名。自己写爬虫又容易被系统识别拦截。经过反复测试和调整，最终把两种方法结合起来，成功将大部分地名爬取下来并显示在前端。过程中遇到的主要问题是爬取到的名称不符合要求，比如想保存孟加拉语却存了英文，想保存中文却没有。我通过查阅CSDN等技术网站，并借助大模型帮助修改代码，逐步解决了这些问题。阅读方面，我读了《计算机文化》第20版。书中对“计算机文化”的解释让我改变了之前只关注操作技能的看法，认识到真正的计算机文化是处理信息的能力。关于社交媒体和网络安全的内容也引发了我的反思，比如我们在社交平台上展示的不是完整的自己，平台的商业模式是靠卖用户注意力赚钱，网络安全最薄弱的环节其实是人。编程章节则让我明白，学编程是为了培养拆解问题的思维方式。总的来说，这一周在技术和认识上都有收获。
